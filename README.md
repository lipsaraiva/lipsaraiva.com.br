# lipsaraiva.com.br
Meu site
Deploy automatico para o VPS

## Artigos

1. Copie `posts/_modelo.md` para `posts/nome-do-artigo.md` e escreva (o modelo explica a sintaxe).
2. Imagens em `assets/artigos/`.
3. `npm install` (só na primeira vez) e `npm run build`.
4. Commit + push — o VPS publica.

A pasta `artigos/` e o `sitemap.xml` são gerados pelo build: não edite à mão.
Links de afiliado (Amazon, Mercado Livre, Shopee etc.) são detectados sozinhos — lista em `build.mjs`.
